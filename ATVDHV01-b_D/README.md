# Banco da Cooperativa (TypeScript + Node.js)

## Rodar
npm install
npm run dev

## Ou compilar
npm run build
npm start

## Pastas
- src/dominio: Cliente e Conta (atributos privados com getters e setters)
- src/excecoes: SaqueException (abstrata) e 4 excecoes
- src/notificacao: CanalNotificacao (interface) e SMS, Email, App, WhatsApp
- src/servicos: ServicoSaque
